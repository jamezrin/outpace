# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/jamezrin/outpace-stream/security/advisories/new).
Don't open a public issue, discussion or pull request with exploit details.

Include the Outpace version (`outpace --version`), how you run it, and the steps to reproduce.
The same identifier rules as for bug reports apply: don't include content ids, infohashes,
stream names, source URLs, tokens or IP addresses that aren't needed to show the problem.

## Supported versions

Fixes go into the latest release and the `edge` image. See
[Releases and Versions](https://github.com/jamezrin/outpace-stream/wiki/Releases-and-Versions).

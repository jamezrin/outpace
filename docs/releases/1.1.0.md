# Outpace 1.1.0

For publication status and downloads, see the
[GitHub Release](https://github.com/outpace-stream/outpace-engine/releases/tag/v1.1.0).
These notes accompany the reviewed release commit; source documentation can precede publication.

Outpace 1.1.0 is a minor release. It adds an opt-in AceStream identity profile and brings a few
always-on peer and DHT details closer to the original engine. The new profile is off by default,
and no existing default changes.

## Features

- **Opt-in AceStream identity**
  ([#476](https://github.com/outpace-stream/outpace-engine/pull/476)). With
  `OUTPACE_ACESTREAM_IDENTITY=1`, the values Outpace shows on the public network match one
  official Linux engine profile: peer handshakes, search requests, catalog requests, UPnP mapping
  labels and broadcast descriptors. The local API, metrics, logs and startup lines stay Outpace's.
  `OUTPACE_ACESTREAM_IDENTITY_VERSION`, `_PLATFORM`, `_DEVICE_ID`, `_HARDWARE_KEY`, `_ASN`,
  `_COUNTRY` and `_USER_AGENT` override parts of the profile; they are validated at startup and
  ignored while the switch is off. See
  [Engine Camouflage](https://github.com/outpace-stream/outpace-engine/wiki/Engine-Camouflage).
  - The first start with the profile on writes a random device id to `acestream-device-id` in
    `OUTPACE_DATA_DIR` (mode `0600` on Unix). Keep the data directory or volume to keep the id.
  - When `_ASN` and `_COUNTRY` are not both set, Outpace makes one HTTPS lookup to RIPEstat
    (`stat.ripe.net`) after two distinct peers report the same public address. Redirects are not
    followed. Setting both variables skips the lookup.
  - Compose does not forward these variables; set them in a Compose override.

## Changes with the profile off

- DHT messages carry the engine's client version tag, use one node id for the whole process so
  tokens from a `get_peers` walk stay valid for the announces that follow, and send an explicit
  `port` without `implied_port`.
- Peer handshakes advertise the real listen port and host uptime.
- Catalog responses sent gzip-encoded are decoded, bounded by the same response size limit.

## Distribution

Targets, packages, images and signer identity are unchanged from
[1.0.2](https://github.com/outpace-stream/outpace-engine/blob/main/docs/releases/1.0.2.md#distribution).
Images are published to `ghcr.io/outpace-stream/outpace-engine` (`1.1.0`, `1.1.0-minimal`,
`latest`, `minimal`).

## Upgrade and rollback

Upgrading from 1.0.3 needs no configuration change. Restart, then check `/healthz` and playback.
Keep the 1.0.3 binary or image for rollback. A rollback leaves `acestream-device-id` in the data
directory, where 1.0.3 ignores it.

## Validation and limits

The profile is covered by unit tests for settings validation, the engine-shaped search, catalog
and handshake encodings, device id persistence, the shared search response budget, and
public-address corroboration by distinct peers. The DHT wire shapes are checked byte for byte
against the engine's. No live search, catalog or playback check with the profile on, no multi-hour
soak and no hardware qualification was performed for this release.

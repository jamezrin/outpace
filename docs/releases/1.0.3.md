# Outpace 1.0.3

For publication status and downloads, see the
[GitHub Release](https://github.com/outpace-stream/outpace-engine/releases/tag/v1.0.3).
These notes accompany the reviewed release commit; source documentation can precede publication.

Outpace 1.0.3 is a patch release. Live streams whose peers hold less history than the startup
buffer target now start in a few seconds instead of waiting for the 15-second startup deadline. It
changes no defaults and needs no configuration change.

## Fixes

- **Short live backlogs no longer wait for the startup deadline**
  ([#474](https://github.com/outpace-stream/outpace-engine/issues/474),
  [#475](https://github.com/outpace-stream/outpace-engine/pull/475)). When the peers of a live
  stream held less history than `OUTPACE_PREBUFFER_MS` (30 seconds by default), Outpace downloaded
  all of it in about a second and then held it until `OUTPACE_PREBUFFER_TIMEOUT_MS` (15 seconds)
  expired. The startup buffer now releases as soon as every piece up to the live edge has arrived,
  and the `[prebuffer]` log line reports `reason=BacklogExhausted`. In a side-by-side comparison on
  such a stream, the first byte arrived after about 2 seconds instead of about 16, within a second of
  the original engine. The trade-off is that such a stream starts with the lead its peers hold
  rather than whatever the deadline would have accumulated; the original engine behaves the same
  way. Streams whose peers hold the full target still release on `TargetDuration` as before, and
  VOD is unchanged.

## Distribution

Targets, packages, images and signer identity are unchanged from
[1.0.2](https://github.com/outpace-stream/outpace-engine/blob/main/docs/releases/1.0.2.md#distribution).
Images are published to `ghcr.io/outpace-stream/outpace-engine` (`1.0.3`, `1.0.3-minimal`,
`latest`, `minimal`).

## Upgrade and rollback

Upgrading from 1.0.2 needs no configuration change. Restart, then check `/healthz` and playback.
Keep the 1.0.2 binary or image for rollback.

## Validation and limits

The new release reason is covered by unit tests for an exhausted and an outstanding backlog,
position updates that arrive after the last chunk, media still readable behind an exhausted
position, sources without live position stats, and an empty buffer. Simultaneous live comparisons
against the original engine 3.2.11 were run on two short-backlog streams and one healthy stream, as
recorded in [#475](https://github.com/outpace-stream/outpace-engine/pull/475). No new multi-hour
soak or hardware qualification was performed for this release.

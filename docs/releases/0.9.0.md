# Outpace 0.9.0

This release improves live protocol compatibility, verified piece serving and bounded actor responsiveness. It does not establish 24/7 production readiness.

- Include optional live descriptor hash fields while preserving legacy wrapped VOD identities.
- Avoid bounded peer-channel deadlocks through credit-based request admission and nonblocking command delivery.
- Publish and serve only complete accepted pieces, with bounded memory and disk lifetimes.
- Add shared configurable session admission. `OUTPACE_MAX_SESSIONS` unset or zero remains unlimited; positive values cap provider resources while existing sessions remain joinable.
- Keep pool control and cancellation responsive during gossip, publication, reciprocal reads, activation writes and output backpressure; use bounded incremental statistics.
- Strengthen HTTP recovery, decoder and owned VLC validation tooling and lifecycle cleanup.

## Validation limits

Reviewed changes passed their repository tests and CI. Bounded deployed comparisons demonstrated sampled decode progress, but the latest long matched observation stopped on both player progress watchdogs before its required sustained window. The underlying cause remains unresolved; shared failure does not establish a source-wide outage. No automatic live retry was performed.

The sustained-validation, startup/parity and historical recovery investigations remain open. The milestone remains open. This release is not a production signoff, playback-quality guarantee, memory-leak exclusion or claim that the historical stall is fixed. Official playback redirect ownership relies on the operator-approved API contract; internal ownership was not independently proven. Existing deployment routing and configuration were preserved.

# Broadcast Startup Profiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Preserve the selected Luna test/Sol product-and-review workflow; root orchestrates sequential file ownership.

**Goal:** Finish #51's supported metadata and explicit sizing slice through one immutable named startup profile shared by PUT, RTMP, HTTP pull, and CLI mint/resume.

**Architecture:** A focused presence-preserving parser resolves fresh profiles and compares explicit fields with raw persisted descriptors. The registry owns the immutable dictionary, validates persisted identity and effective geometry before reservation/store exposure, and supplies geometry and stored trackers to ingest/announcements. Runtime performs read-only preflight before side effects and rechecks at initialization; persistence schema and existing lifecycle fences stay intact.

**Tech Stack:** Pinned Rust toolchain, existing serde/serde_json, Tokio, axum, RSA/live signing, bencode/transport codecs, and memory/disk piece stores. No new dependency or test framework.

**Spec:** [Approved broadcast options design](../specs/2026-10-24-broadcast-options-design.md). Read it in full; its bounds and resume rules are normative.

## Global Constraints

- “No automatic bitrate detection, transcoding, hot reload, per-profile trackers, arbitrary metadata bag, new source protocol, or compatibility endpoint is included.” Preserve #206 pull/retry and #207 admission, bind defaults, seeding limits, cancellation and persistence guarantees.
- “The JSON input is at most 262144 bytes and 64 profiles.” Names use `valid_broadcast_name`: 1–64 ASCII bytes, alphanumeric or `._-`, excluding `.` and `..`. Reject duplicate decoded names, duplicate/unknown fields, blank/non-UTF-8/null/non-object/trailing input.
- Fresh optional fields: title 1–256 UTF-8 bytes; bitrate integer 1–2305843009213693951 bytes/second; piece length power of two 65536–1048576; quality exactly `auto`, `SD`, `HD`; categories 0–32 distinct strings of 1–128 UTF-8 bytes. Reject null, wrong types, fractional/exponent forms, edge whitespace and Unicode control characters. Preserve accepted bytes and category order; explicit `[]` stays empty.
- “Fresh identity when absent”: path name, `8375`, `65536`, `auto`, `["other"]`. “`chunk_length` is fixed at 16384 and is not an accepted profile key.” Preserve absence during serde round trips; present defaults remain serialized and asserted.
- “On resume, stored transport bytes and private key are authoritative.” Compare only present fields against raw fields; absent stored fields are not defaults. Never remint, normalize, insert fields or re-encode a resumed transport. Keep the exact legacy fresh descriptor field set/types/encoding and `allow_public_trackers=1`.
- Persisted live pieces may be positive multiples of `16384` up to `8388608`, including non-powers of two. Require `0 < signature_len < piece_length`, actual key modulus length, checked chunk-count/`u16`, bencode/`i64`, target `usize` and object-size conversions. Omitted legacy bitrate/metadata may exceed new-profile bounds under existing consumer rules.
- “Every fresh effective profile, the unprofiled default, and every valid reloaded broadcast must fit at least one **full wire piece** in `seed_store_bytes`, on both memory and disk.” Retain memory-pool upper bounds, disk protections/fallback and existing reservation advance/atomic-save rules; no budget resizing or new rollback guarantee.
- “Keep `OUTPACE_TRACKERS` as the sole global fresh-mint tracker input” with existing unset/blank behavior, filtering, 64-entry/256-byte caps and non-UDP preservation. Resume/announcements use stored trackers, including empty lists, for both announcement keys. No new announcer protocol or privacy claim.
- Public failures: `invalid_broadcast_options`, `broadcast_store_too_small`, `broadcast_options_conflict`, existing `broadcast_state_invalid`. Startup/CLI exit nonzero; runtime options conflict is HTTP 409 and RTMP uses the same stable code. New errors/Debug/logs disclose no input values or keys; operational events use `alog!`.
- User's execution ownership supersedes the spec's earlier Sol-only-specification wording: **Luna authors/migrates all tests and runs every test/build/fmt/clippy/hygiene/hook-running commit; Sol implements product/docs and reviews.** Whole-file handoffs serialize shared files; nobody reverts others' edits. Keep the root checkout's dirty state untouched.
- Work remains on the verified `feat/broadcast-options-51` topic based on `main`; no new checkout is needed. Synthetic data only; never read the identifier registry or use real content ids, infohashes or stream names. No public-network/live/FFmpeg probes, installation, deployment or release.

## Review Focus

- Escaped duplicate names, explicit null and explicit defaults must retain distinct rejection/assertion behavior in env and direct Config paths. Task 1: `options51_schema_presence_and_limits` and `options51_raw_resume_matching`.
- A valid later profile or disk record that conflicts or exceeds capacity must fail before normalizer/cache/identity effects, even without a source; a changed record must fail again at real initialization. Task 1: `options51_preflight_precedes_effects` and `options51_reload_revalidates`.
- Legacy records with absent metadata or consumer-valid non-origination geometry must resume byte-for-byte when unasserted; lossy metadata projection must never make an explicit field match. Task 1: `options51_raw_resume_matching` and `options51_legacy_geometry_and_cursor`.

- Process tracker changes must not redirect resumed announcements or refill an empty stored list; both keys still use the entry-owned cancellation/deduplication path. Task 1: `options51_transport_trackers_are_authoritative`.

**Parser/config contract (`broadcast_options.rs`):**

- `BroadcastOptions { title: Option<String>, bitrate_bytes_per_sec: Option<u64>, piece_length: Option<u64>, quality: Option<String>, categories: Option<Vec<String>> }`, with public fields, `Clone/Default/PartialEq/Eq`, redacted Debug and presence-preserving Serialize/custom strict Deserialize. Present-value deserialization must reject null; numeric deserialization accepts integer tokens only. Use duplicate-aware map visitors and `Deserializer::end()`, never an intermediate `Value`/map that erases duplicates.
- `pub(crate) fn parse_broadcast_options(raw: Option<&str>) -> Result<BTreeMap<String, BroadcastOptions>, BroadcastOptionsError>`; `None` and `{}` are empty. `pub(crate) fn validate_broadcast_options(options: &BTreeMap<String, BroadcastOptions>) -> Result<(), BroadcastOptionsError>` validates direct Rust values, names/count and compact serialized size including every present default. `BroadcastOptionsError` Display/Error expose only `invalid_broadcast_options`.
- `pub(crate) struct ResolvedBroadcastOptions` contains concrete `title: String`, `bitrate_bytes_per_sec: u64`, `piece_length: u64`, `quality: String`, `categories: Vec<String>`. `BroadcastOptions::resolve_fresh(&self, name: &str) -> Result<ResolvedBroadcastOptions, BroadcastOptionsError>` applies defaults after validation; `matches_descriptor(&self, raw: &Bencode) -> bool` compares only present fields with exact raw bencode types/bytes/order, without consumer metadata normalization.
- In `runtime.rs`, `fn apply_broadcast_options_env(config: &mut Config, raw: Result<String, std::env::VarError>) -> Result<(), BroadcastOptionsError>` maps NotPresent to empty and NotUnicode to the fixed error; `config_from_env` calls it. This is the same boundary used by direct-value env tests, avoiding process-global env mutation.

**Registry/geometry contract (`broadcast.rs`):**

- `BroadcastGeometry { piece_length: u64, chunk_length: u64 }` is immutable and copyable; `BroadcastGeometry::from_transport(descriptor: &TransportDescriptor, signature_len: usize) -> Result<Self, BroadcastError>` owns persisted geometry/signing/allocation checks. Add `Broadcast.geometry: BroadcastGeometry` and `Broadcast.trackers: Arc<Vec<String>>`, populated once from validated transport. Existing constants remain legacy defaults, not runtime geometry.
- `validate_persisted(name: &str, record: &PersistedBroadcast, options: &BroadcastOptions) -> Result<ValidatedPersistedBroadcast, BroadcastError>` is a private shared read-only helper. Its result holds `auth: LiveSourceAuth`, `geometry: BroadcastGeometry`, `trackers: Vec<String>`, `start: u64`; validate key/pubkey/live/RSA/required identity/outpace_name/cursor plus raw matches before any save/lease. Retain original record transport/key verbatim for persistence; computed `start` is the existing reservation high-water/migration rule.
- `pub(crate) fn preflight_broadcasts(config: &Config) -> Result<(), BroadcastStartupError>` reads records with `BroadcastPersist::load_all`, checks default/all declared fresh profiles and every valid stored geometry against the budget, and applies configured-source/profile invalid-record policy. `BroadcastStartupError::{StoreTooSmall, Broadcast(BroadcastError)}` displays only `broadcast_store_too_small` or the wrapped stable code; it does not mint/reserve/create stores or mutate directories. Schema validation precedes this call.
- Preserve `new()`/`with_persist(...)` as empty-dictionary wrappers. Add `new_with_options(options: BTreeMap<String, BroadcastOptions>) -> Result<Arc<Self>, BroadcastOptionsError>` and `with_persist_and_options(data_dir: &Path, cache_type: CacheType, cache_dir: PathBuf, options: BTreeMap<String, BroadcastOptions>) -> Result<Arc<Self>, BroadcastOptionsError>`; dictionary validation precedes installation and there is no setter/hot mutation.
- Remove the per-call `title` argument from `prepare`, `mint` and `acquire_producer`. Public signatures become `mint(&self, name: &str, trackers: &[String], seed_registry: &SeedRegistry, store_bytes: u64) -> Result<Broadcast, BroadcastError>` and `acquire_producer(&self, name: &str, trackers: &[String], seed_registry: &SeedRegistry, store_bytes: u64, kind: ProducerKind) -> Result<(Broadcast, ProducerSession), BroadcastError>` (both async). Source commitment uses this same preparation policy. Fresh title comes from profile or path name; no caller can override it.
- `build_descriptor(name: &str, options: &ResolvedBroadcastOptions, trackers: &[String], pubkey_der: &[u8]) -> Bencode` retains the existing field set/encoding. `initialize` receives the selected presence-preserving options and reuses `validate_persisted`; check capacity before key generation/save/lease, and also before returning an already initialized entry to a direct caller with an inconsistent budget (`StateInvalid`). Add `BroadcastError::OptionsConflict` → `broadcast_options_conflict`.
- `reload_persisted(&self, seed_registry: &SeedRegistry, store_bytes: u64, configured_sources: &BTreeSet<String>) -> Result<Vec<Broadcast>, BroadcastError>` (async) adds just the source-name set derived from already validated Config; existing standalone callers pass an empty set. Propagate conflicts/capacity failures; malformed records named in this set or the registry's options dictionary are fatal on actual reload, including records changed since preflight. Unrelated malformed records retain tombstones. This avoids a new mutable registry setting or source-config dependency in initialization.
- `ensure_announcing(&self, name: &str, port: watch::Receiver<Option<u16>>) -> Result<(), BroadcastError>` (async) uses `Broadcast.trackers`. Luna adapts existing test `AnnouncerFactory` to `Fn([u8; 20], Vec<String>) -> AnnounceFuture`; keep it `cfg(test)`. No production announcement API exists just for tests.

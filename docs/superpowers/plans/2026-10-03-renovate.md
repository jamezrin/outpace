# Renovate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `rust-toolchain.toml` the only Rust version pin, and configure Renovate to automerge non-major dependency updates.

**Architecture:** Release and ARMv7 workflows install the root toolchain file through `actions-rust-lang/setup-rust-toolchain@v2`. The Docker builder installs that same file with rustup on `debian:bookworm-slim`. Renovate updates the toolchain channel from `rust-lang/rust` releases and groups non-major Cargo updates into one automerged pull request.

**Tech Stack:** GitHub Actions, Docker, rustup, Renovate, PyYAML.

## Global Constraints

- `rust-toolchain.toml` stays at the repository root with `channel = "1.96.1"` and `components = ["clippy", "rustfmt"]`.
- Workflows use `actions-rust-lang/setup-rust-toolchain@v2` with no `toolchain` input, `cache: false`, and `build-warnings: ""`.
- Release jobs pass `target: ${{ matrix.target }}`. The ARMv7 job passes `target: ${{ env.TARGET }}`.
- Checkout stays the step immediately before Install Rust.
- The builder stage is `FROM debian:bookworm-slim AS builder` and installs rustup from `https://sh.rustup.rs` with `--default-toolchain none`, `--profile minimal`, `--no-modify-path`, and `-y`.
- `RUSTUP_HOME=/usr/local/rustup`, `CARGO_HOME=/usr/local/cargo`, and `PATH=/usr/local/cargo/bin:$PATH`.
- The builder copies `rust-toolchain.toml`, runs `rustup show`, then copies the workspace and runs `cargo build --locked --release -p ace-engine --bin outpace`.
- The runtime stage stays `debian:bookworm-slim` and does not copy `/usr/local/cargo` or `/usr/local/rustup`.
- `renovate.json` extends `config:recommended` and sets `platformAutomerge` to true.
- The regex manager matches `/(^|/)rust-toolchain\.toml$/`, captures `channel\s*=\s*"(?<currentValue>\d+\.\d+\.\d+)"`, uses dependency name `rust`, package name `rust-lang/rust`, datasource `github-releases`, versioning `semver`, and `extractVersion` `^(?<version>\d+\.\d+\.\d+)$`.
- Package rules automerge `minor`, `patch`, `pin`, and `digest`; group Cargo `minor`, `patch`, and `pin` as `cargo dependencies` with slug `cargo`; set `automerge` false for `major`.
- Do not add `lockFileMaintenance`, digest pinning, or a workflow that runs Renovate.
- Do not edit `docs/linux-portability.md` or historical specs, including `docs/superpowers/specs/2026-07-07-release-binaries-and-docker-design.md`.
- Do not change release artifacts, supported targets, runtime image defaults, or `hygiene.yml`.
- Do not add `rust-toolchain.toml` to `.dockerignore`.
- Keep the root checkout on `main`. Implement on branch `feat/renovate` from `main` in worktree `/home/jamezrin/dev/outpace-renovate`. There is no GitHub issue.
- Every command below runs in `/home/jamezrin/dev/outpace-renovate` after Task 1 creates it.

import pathlib, sys
text = pathlib.Path("Dockerfile").read_text()
if "FROM debian:bookworm-slim AS runtime" not in text:
    sys.exit("runtime stage missing")
builder, runtime = text.split("FROM debian:bookworm-slim AS runtime", 1)
needles = [
    "FROM debian:bookworm-slim AS builder",
    "https://sh.rustup.rs",
    "--default-toolchain none",
    "--profile minimal",
    "--no-modify-path",
    "RUSTUP_HOME=/usr/local/rustup",
    "CARGO_HOME=/usr/local/cargo",
    "PATH=/usr/local/cargo/bin:$PATH",
    "COPY rust-toolchain.toml ./",
    "RUN rustup show",
    "cargo build --locked --release -p ace-engine --bin outpace",
]
for needle in needles:
    if needle not in builder:
        sys.exit(f"builder missing: {needle}")
if "ARG RUST_VERSION" in text or "FROM rust:" in text:
    sys.exit("Dockerfile still pins a Rust image")
if "COPY --from=builder /usr/local/cargo" in text or "COPY --from=builder /usr/local/rustup" in text:
    sys.exit("runtime copies the toolchain")
order = [
    "COPY rust-toolchain.toml ./",
    "RUN rustup show",
    "COPY Cargo.toml Cargo.lock ./",
    "cargo build --locked --release -p ace-engine --bin outpace",
]
positions = [builder.index(item) for item in order]
if positions != sorted(positions):
    sys.exit("builder steps out of order")
for needle in [
    "USER outpace",
    "OUTPACE_BIND=0.0.0.0:6878",
    "COPY --from=builder /src/target/release/outpace /usr/local/bin/outpace",
]:
    if needle not in runtime:
        sys.exit(f"runtime missing: {needle}")
print("ok")
PY

- [ ] **Step 2: Replace the Dockerfile**

Write `Dockerfile` as:

```dockerfile
# syntax=docker/dockerfile:1

FROM debian:bookworm-slim AS builder
WORKDIR /src

RUN apt-get update \
    && apt-get install -y --no-install-recommends \
        build-essential \
        ca-certificates \
        curl \
        pkg-config \
    && rm -rf /var/lib/apt/lists/*

ENV RUSTUP_HOME=/usr/local/rustup \
    CARGO_HOME=/usr/local/cargo \
    PATH=/usr/local/cargo/bin:$PATH

RUN curl --proto '=https' --tlsv1.2 -fsSL https://sh.rustup.rs \
    | sh -s -- -y --default-toolchain none --profile minimal --no-modify-path

COPY rust-toolchain.toml ./
RUN rustup show

COPY Cargo.toml Cargo.lock ./
COPY crates ./crates
# tools/ is copied so Cargo can resolve every workspace member's manifest; the
# `-p ace-engine` build below still only compiles the engine, not the tools.
COPY tools ./tools

RUN cargo build --locked --release -p ace-engine --bin outpace

FROM debian:bookworm-slim AS runtime

LABEL org.opencontainers.image.source="https://github.com/jamezrin/outpace" \
      org.opencontainers.image.licenses="AGPL-3.0-or-later"

RUN apt-get update \
    && apt-get install -y --no-install-recommends ca-certificates curl \
    && groupadd --system outpace \
    && useradd --system --gid outpace --home-dir /var/lib/outpace --shell /usr/sbin/nologin outpace \
    && mkdir -p /var/lib/outpace \
    && chown outpace:outpace /var/lib/outpace \
    && rm -rf /var/lib/apt/lists/*

COPY --from=builder /src/target/release/outpace /usr/local/bin/outpace
COPY LICENSE /usr/share/doc/outpace/LICENSE

ENV OUTPACE_BIND=0.0.0.0:6878 \
    OUTPACE_RTMP_BIND=0.0.0.0:1935 \
    OUTPACE_DATA_DIR=/var/lib/outpace

EXPOSE 6878/tcp 1935/tcp 8621/tcp
VOLUME ["/var/lib/outpace"]

USER outpace
ENTRYPOINT ["outpace"]
CMD ["serve"]
```

- [ ] **Step 1: Run the config check and confirm it fails**

```bash
python3 - <<'PY'
import json, pathlib, sys
data = json.loads(pathlib.Path("renovate.json").read_text())
if data.get("extends") != ["config:recommended"]:
    sys.exit(f"extends is {data.get('extends')!r}")
if data.get("platformAutomerge") is not True:
    sys.exit("platformAutomerge is not true")
if "lockFileMaintenance" in data:
    sys.exit("lockFileMaintenance must be absent")
managers = data.get("customManagers")
if not isinstance(managers, list) or len(managers) != 1:
    sys.exit("expected one custom manager")
manager = managers[0]
expected_manager = {
    "customType": "regex",
    "managerFilePatterns": ["/(^|/)rust-toolchain\\.toml$/"],
    "matchStrings": ['channel\\s*=\\s*"(?<currentValue>\\d+\\.\\d+\\.\\d+)"'],
    "depNameTemplate": "rust",
    "packageNameTemplate": "rust-lang/rust",
    "datasourceTemplate": "github-releases",
    "versioningTemplate": "semver",
    "extractVersionTemplate": "^(?<version>\\d+\\.\\d+\\.\\d+)$",
}
for key, value in expected_manager.items():
    if manager.get(key) != value:
        sys.exit(f"{key} is {manager.get(key)!r}")
rules = data.get("packageRules")
if not isinstance(rules, list) or len(rules) != 3:
    sys.exit("expected three package rules")
if rules[0].get("matchUpdateTypes") != ["minor", "patch", "pin", "digest"] or rules[0].get("automerge") is not True:
    sys.exit(f"non-major rule is {rules[0]!r}")
if rules[1].get("matchManagers") != ["cargo"] or rules[1].get("matchUpdateTypes") != ["minor", "patch", "pin"]:
    sys.exit(f"cargo match is {rules[1]!r}")
if rules[1].get("groupName") != "cargo dependencies" or rules[1].get("groupSlug") != "cargo":
    sys.exit(f"cargo group is {rules[1]!r}")
if rules[2].get("matchUpdateTypes") != ["major"] or rules[2].get("automerge") is not False:
    sys.exit(f"major rule is {rules[2]!r}")
print("ok")
PY
```
